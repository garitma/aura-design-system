Aura does not ship Emil Kowalski’s skills, and `aura blueprint` does not install them. Re-running blueprint deletes the copies an older CLI wrote into `.cursor/skills/` and `.agents/skills/`.

Install the ones you want from [emilkowalski/skills](https://github.com/emilkowalski/skills). The skill names, the install command, how to invoke one, and the findings format are on [Audits](/docs/audits).
