## Rules

These rules define foundations and principles for the Aura Design System. You can install them via the registry or copy them into your project's `.cursor/rules/` directory.

```bash
pnpm dlx shadcn@latest add @aura/rules
```

Form system — useFormDynamic, Form components, validation (validateFormData), and field composition.

### [Color Rules](/docs/rules/fundations-colors)

Aura uses a 12-step color scale for both `accent` and `gray` scales. Each step has specific use cases.

### [DESIGN.md (narrative spec)](/docs/rules/design-md)
