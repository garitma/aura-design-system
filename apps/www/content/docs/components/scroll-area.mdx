## Installation
Make sure that `namespace` is set in your component.json file. Namespace docs: [Learn more about namespaces](/docs/namespace)
```bash
pnpm dlx shadcn@latest @aura/scroll-area
```



## Props

### ScrollArea

All props are passed through to the underlying component. See the [Radix UI documentation](https://www.radix-ui.com/primitives) for the full API.

| Prop | Type | Default |
|------|------|---------|
| *All props from* | `React.ComponentPropsWithoutRef<typeof ScrollAreaPrimitive.Root` | - |
