title: Scroll Area

---

## Installation
Make sure that `namespace` is set in your component.json file. Namespace docs: [Learn more about namespaces](/docs/namespace)
```bash
pnpm dlx shadcn@latest add @aura/scroll-area
```



## Props

### ScrollArea


| Prop | Type | Default |
|------|------|---------|
| *All props from* | `React.ComponentPropsWithoutRef&lt;typeof ScrollAreaPrimitive.Root` | - |

### ScrollBar


| Prop | Type | Default |
|------|------|---------|
| *All props from* | `React.ComponentPropsWithoutRef&lt;typeof ScrollAreaPrimitive.ScrollAreaScrollbar` | - |
