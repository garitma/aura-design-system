## 12-Step Color System (Radix UI-inspired)

The application uses a semantic 12-step color scale system providing consistent theming, proper contrast ratios, and simplified dark mode support.

### Color Scales

**Gray Scale**: `gray-1` to `gray-12` - Neutral colors for text, backgrounds, and UI elements
**Accent Scale**: `accent-1` to `accent-12` - Primary brand colors for interactive elements
**Alpha Variants**: `gray-a1` to `gray-a12`, `accent-a1` to `accent-a12` - Semi-transparent overlays

### The 12 Steps Explained

1. **Step 1** - `bg-gray-1` / `bg-accent-1` - Application background
2. **Step 2** - `bg-gray-2` / `bg-accent-2` - Subtle background (cards, code blocks, containers)
3. **Step 3** - `bg-gray-3` / `bg-accent-3` - UI element background (inputs, selects, buttons in normal state)
4. **Step 4** - `bg-gray-4` / `bg-accent-4` - Hovered UI element background
5. **Step 5** - `bg-gray-5` / `bg-accent-5` - Active/Selected UI element background
6. **Step 6** - `border-gray-6` / `border-accent-6` - Subtle borders and separators
7. **Step 7** - `border-gray-7` / `border-accent-7` - UI element borders and focus rings
8. **Step 8** - `border-gray-8` / `border-accent-8` - Hovered UI element border
9. **Step 9** - `bg-accent-9` - Solid backgrounds (primary buttons, badges)
10. **Step 10** - `bg-accent-10` - Hovered solid backgrounds
11. **Step 11** - `text-gray-11` / `text-accent-11` - Low-contrast text (secondary text, placeholders)
12. **Step 12** - `text-gray-12` / `text-accent-12` - High-contrast text (primary text, headings)
